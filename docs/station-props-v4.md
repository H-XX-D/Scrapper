# Station equipment, v4

Source files: `src/station-props.js`, `src/station-visuals.js`, `src/atlas.js`, `src/audio.js`, `src/world-complexity.js`, `src/app.js`. Preview sheets through `atlas.html`. Exact generation prompts are recorded in `docs/v4-art-prompts.json`; source images remain unchanged.

The requested equipment is placed along continuous wall runs. Placement excludes doors, stair treads, lift approaches, mission devices, supplies, spawners and existing infestation patches. Large equipment is wall aligned; small objects face the viewer. The generator has its own integer hash so placement does not consume combat RNG. There are 28 equipment and clutter types, including four reused legacy types. The default campaign's measured density is in `artifacts/prop-density-v4.json`.

Pumps move, panels pulse their waveforms, life-support tanks bubble, compactors open/press/release, vent covers cycle, manifolds vary their indicators, junction cabinets spark and filters rotate. Exhaust uses separate padded pixel sprites, distance culling and no depth writes. Vent hisses and compactor clunks begin during the visible discharge portion of each cycle. The world audio bus uses distance, pan, occlusion checks and voice limits; weapon mixing is unchanged.

A first movement check found that small crates protruded far enough from their walls to obstruct cell centers used by guidance. The offset is now 0.3 world units, and all 24 physical compass routes (main objective and upper service route for each chapter) pass with equipment installed. Collision queries use nearby buckets; route caches are invalidated after adding equipment. Required interactions remain reachable across two seeds per chapter. Optional supplies are compared only where the original map already had a path: seed 71 chapter 1 has pre-existing unreachable service-spur supplies, unrelated to the new props.

Saves regenerate the same props and restore their phases from mission elapsed time. Loading resolves a player's overlap with a newly added prop by moving a short distance away from the wall while retaining health and floor. Room protocol 3 requires the v4 build on all peers; no extra per-prop network payload is needed.

Dependency review: Recall's current v3 verification and original-art correction were expanded before editing, including linked historical evidence. The graph impact packet (`artifacts/props-recall-impact.json`) contains historical project links rather than a complete code dependency graph. Direct source review covered atlas/export consumers, procedural placement, collision/navigation, save restoration, replicated mission time and audio. No other project was edited. Original title, HUD, chapter layouts, low ceilings, infestation, combat and single-wipe behavior remain.

This is procedural decoration and animated station equipment. The new background panels and compactors are not additional puzzles or destructible machines. Live verification uses test teleports for close-up inspection and save preparation, alongside separate actual-movement regression tests. A full human campaign balance pass and cross-network latency soak remain outside the evidence recorded for this build.
